## Установка

```bash
curl -sSL https://raw.githubusercontent.com/MAX1T1A/statusphere/master/install.sh | bash
```

Ставит бинарник в `~/.local/bin/` и добавляет алиас `sstatus`. После установки перезапусти шелл (новый терминал или `source ~/.bashrc` / `source ~/.zshrc`).

Нужен Linux.

## Первый запуск

Создать аккаунт (своя комната, ты — владелец):

```bash
sstatus --register https://ss.ug3n.com
```

Запустить:

```bash
sstatus
```

## Подключиться к друзьям

Позвать к себе в комнату:

```bash
sstatus --invite          # покажет инвайт (в нём зашит твой сервер, действует 1 час)
```

Войти по инвайту друга — аккаунт заведётся сам на его сервере, отдельная регистрация не нужна:

```bash
sstatus --join <инвайт>
sstatus                   # и смотришь комнату
```

## Второе устройство

```bash
sstatus --new-device                              # на старом устройстве → печатает код
sstatus --link https://ss.ug3n.com --code <код>   # на новом устройстве
```

Новое устройство попадает в ту же комнату.

## Управление

```bash
sstatus --set-name "Имя"        # как тебя видят в комнате
sstatus --devices               # список твоих устройств
sstatus --revoke <device_id>    # отозвать устройство
sstatus --members               # кто в комнате
sstatus --kick <account_id>     # выгнать участника (только владелец)
```

Потерял все устройства — восстановись по сохранённым `account_id` и `account_secret`:

```bash
sstatus --recover https://ss.ug3n.com --account <account_id> --secret <account_secret>
```

## Инкогнито

Не всегда хочется, чтобы комната видела, что у тебя открыто.

```bash
sstatus --incognito on                    # скрыться, пока не выключишь
sstatus --incognito 45m                   # скрыться на 45 минут
sstatus --incognito on --note "созвон"    # с подписью, которую видят друзья
sstatus --incognito off
sstatus --incognito status                # что комната видит прямо сейчас
```

В комнате при этом остаёшься: карточка живая, музыка играет, просто без приложений.
Вместо твоего окна друзья видят «off the radar» или твою подпись. То же самое
переключается в меню: `Enter → settings → Incognito`.

Фильтр стоит до отправки, поэтому скрытое не уходит ни друзьям, ни в историю на
сервере - экранное время за это время просто пустое. Проверяется так:

```bash
sstatus --published    # ровно тот JSON, который уходит с этой машины
```

Настройки - `~/.config/statusphere/privacy.json`: два профиля, что публикуется
обычно и что в инкогнито.

```json
{
  "profiles": {
    "normal":    { "apps": "full", "music": "full", "system": "on", "custom": "on" },
    "incognito": { "apps": "off",  "music": "full", "system": "on", "custom": "on" }
  },
  "hide_apps": ["(?i)keepassxc", "(?i)1password", "(?i)bitwarden"]
}
```

- `apps`: `full` (приложение и заголовок окна) · `app` (только приложение) ·
  `busy` (просто «Active») · `off`
- `music`: `full` · `listening` (играет, но не видно что) · `off`
- `system`, `custom`: `on` · `off`
- `hide_apps` - регулярки по приложению и заголовку окна. Работают всегда, а не
  только в инкогнито: пароли и банк не светятся, даже когда ты на виду.
- `announce` - по умолчанию `true`: друзья видят, что человек скрылся, а не
  зависшую карточку. Поставь `false`, если хочешь тишину без объяснений.

## В интерфейсе

- `↑ ↓` — выбрать человека
- `Enter` — меню действий: музыка, экранное время, синхронизация трека, чат, переименование
- `q` — выход · `Esc` — закрыть окно
